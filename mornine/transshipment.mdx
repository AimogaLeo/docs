## 二、现场拆箱与组装流程

### 拆箱优先级

**第一步：拆除外层缠绕膜及打包带**

- 使用美工刀或剪刀切断顶部缠绕膜，注意避免划伤箱体。
- 剪断打包带时注意反弹，建议佩戴护目镜。

**第二步：分离上下两层包装箱**

- 机器人包装箱位于上层，待机站包装箱位于下层。
- 人工搬运将上层机器人包装箱平移至空旷区域。
- **严禁直接倾倒或拖拽**，必须保持箱体水平。

**第三步：分别拆箱组装**

- 先拆待机站包装箱，完成待机站组装。
- 再拆机器人包装箱，完成机器人吊装就位。

<Warning>
  必须先完成待机站组装，再进行机器人吊装就位，确保机器人有稳定的放置与吊装条件。
</Warning>

## 四、二次转运操作流程

### 1. 触发场景

以下情况需启动二次转运包装流程：

- 机器人需从当前场地转移至新的展示 / 使用场地，运输距离较远。
- 设备返厂维修或跨区域调拨。
- 展览活动结束后撤展运输。
- 场地装修 / 改造期间的临时仓储。

### 2. 二次转运包装步骤

**第一步：机器人回装准备**

- 机器人安装在待机站，使用待机站上方吊架对其进行吊装。
- 关闭机器人电源，移除电池，确保处于完全关机状态。
- 将机器人移动至平坦空旷区域，周围预留 **2 m** 操作空间。
- 准备保留的机器人包装箱及全部内衬材料。

<Danger>
  机器人入箱前必须完全断电，并拆下电池单独包装，禁止带电操作。
</Danger>

**第二步：机器人防护包装**

> 以下步骤与出厂打包顺序一致，请参考原包装作业指导书图示操作。

| 步骤 | 操作内容 | 关键要求 |
| :-- | :-- | :-- |
| 步骤一：底部铺设 | 将纸箱底部四周用胶带以“工字形”封好；将纸板（B41000061AA）放入纸箱底部中间位置 | 胶带封底牢固，纸板居中 |
| 步骤二：放置 EPS 下盖 | 将人体下盖（B41000047AA）放入纸箱内 | 确保平稳就位 |
| 步骤三：机器人包裹 | 依次使用 EPE 膜袋将机器人头部、双手、双腿完全包裹 | 各部位包裹到位 |
| 步骤四：入箱固定 | 将包裹好的机器人放入 EPS 人体下盖对应槽位内 | 必须放到位，机器人底部与槽位完全贴合 |
| 步骤五：盖上上盖 | 将人体上盖（B41000048AA）与下盖互套放置 | 若配合松动，使用胶布缠绕一圈加固 |
| 步骤六：封箱加固 | 盖上纸箱摇盖，四周用胶带以“工字形”封好；最后用缠绕膜将纸箱缠绕 5 圈 | 封箱牢固，缠绕膜 5 圈 |

## 五、安全使用注意事项

### 1. 包装操作安全

**人员防护**

- 机器人入箱及封盖作业建议 **2—3 人**协同操作。

**设备防护**

- 机器人入箱前必须完全断电，并拆下电池单独包装，禁止带电操作。
- EPS 泡沫内衬为定制结构，严禁暴力踩踏或挤压。
- EPE 膜袋为一次性防护材料，若破损需联系供应商补充。

### 2. 吊装与搬运安全

**叉车 / 液压车操作**

- 叉齿长度须 **≥1200 mm**，确保完全插入托盘底部。
- 起升时保持匀速，严禁急升急降。
- 堆叠两层包装箱时，上层重心须与下层对齐。

**人工搬运限制**

- 单箱重量超过 **50 kg** 时，禁止单人徒手搬运。
- 搬运 EPS 上下盖时双手托底，避免抓握边缘导致断裂。

### 3. 环境安全要求

**存储环境**

- 包装箱及内衬须存放于室内干燥环境，相对湿度 **≤70%**。
- 远离热源及明火，EPS 材料易燃。
- 避免长期堆叠重物于空纸箱上方，防止变形。

**运输环境**

- 公路运输固定牢靠，防止急刹车导致箱体倾倒。
