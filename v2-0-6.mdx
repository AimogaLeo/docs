## 4 本次更新亮点

### 4.1 语音交互升级

- TTS 音量调节：TTS 设置界面新增音量调节滑动条，可自由调整播报音量。
- 多种语音模式支持：APP 新增语音模式配置，支持讯飞在线、讯飞离线、豆包在线三种模式。
- 修复首次唤醒不拾音问题：解决了启动后首次唤醒第一句话无法拾音的问题。
- 修复 TTS 播报死锁问题：优化双向流式 TTS，避免在异常情况下出现播报卡死。

### 4.2 智能交互增强

- 角色记忆功能：新增角色记忆能力，机器人可记住与用户的交互信息。
- 大模型 IP 自动切换：增加备用大模型 IP 配置，默认流程异常时自动切换 IP，防止服务死锁。
- 环境自检优化：环境自检改用实际 LLM 地址，预检使用实际 FastGPT 地址且不阻断请求。

### 4.3 导航与运动控制

- 避障功能优化：APP 新增动作避障按钮，方便控制机器人避障行为。
- 修复导航避障失败：解决偶发性导航避障失败的问题。

### 4.4 动作与内容

- 爵士舞新增：APP 新增爵士舞动作（需手动导入爵士舞资源包）。
- 动作库多语言翻译：APP 动作库增加多语言翻译支持。
- 修复动作库 UI 遮挡：修复多语言文本过长遮挡关闭按钮的问题。
- 修复舞蹈后头部动作不同步：解决藏族舞完成后语音对话时头部动作不同步的问题。

### 4.5 系统与运维

- 机器人运行时间统计：新增机器人运行时长统计功能，便于了解设备使用情况。
- 云平台服务器切换：APP 开发者选项中新增切换云平台服务器的功能。
- 人脸管理优化：修复人脸删除失败的问题。
- OTA 升级优化：修复部分机器因外网升级程序导致的 OTA 失败问题。
- 日志清理功能恢复：修复 OTA 后无日志清理功能的问题。
